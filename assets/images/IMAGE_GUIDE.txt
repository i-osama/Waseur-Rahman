2. HOW TO ADD OR REPLACE IMAGES (STEP-BY-STEP)
--------------------------------------------------------------------------------

Step A: Copy your image file into the corresponding folder:
        Example: Place your new photo as "project-5.jpg" inside:
        assets/images/projects/project-5.jpg

Step B: Open "script.js" in any text editor (VS Code, Notepad, etc.).

Step C: Locate the `IMAGES` configuration object right at the top of the file:

        const IMAGES = {
          profile: {
            src: "assets/images/profile/profile.jpg",
            alt: "Profile photo of Waseur Rahman"
          },
          ...
          projects: [
            ...
            {
              src: "assets/images/projects/project-5.jpg", // <-- Set your path here!
              alt: "Sustainable denim and gaseous ozone washing trial",
              ...
            }
          ]
        };

Step D: Save `script.js` and refresh your browser!
        - If `src` has a valid path, the website displays your real image with
          a smooth fade-in and lazy loading.
        - If `src` is empty (""), the website continues showing the elegant
          CSS placeholder.

--------------------------------------------------------------------------------
3. HELPFUL TIPS FOR BEST PERFORMANCE
--------------------------------------------------------------------------------

- Compression: Use free tools like https://squoosh.app or https://tinypng.com
  to compress photos before adding them. Aim for under 300KB per project image
  and under 500KB for hero banners.
- Aspect Ratio Locking: The website enforces CSS `object-fit: cover`. This
  means your images will never stretch, distort, or disrupt the grid layout,
  even if your uploaded photo has a slightly different ratio.
- Adding More Gallery Items: You can append as many objects as you like to the
  `gallery: [...]` array in `script.js`. The grid and lightbox will automatically
  adapt!
